# A/B-тестирование: оптимизация конверсии e-commerce лендинга

## Цель проекта

Оценить эффективность новой посадочной страницы (new_page) для интернет-магазина. Определить, приводит ли новый дизайн к статистически значимому увеличению Conversion Rate (CR) с текущих 12% до целевых 13%, и принять обоснованное бизнес-решение о внедрении изменений.

---

## Архитектура и этапы исследования

### 1. Расчёт мощности и дизайн эксперимента (Power Analysis)

Перед анализом данных зафиксирован дизайн теста для детекции минимального измеримого эффекта (MDE = 1 п.п. абсолютных или ~8.3% относительного роста):

- Уровень значимости (α): 0.05
- Мощность теста (1 - β): 0.80
- Базовая конверсия: 12.0%
- Ожидаемая конверсия: 13.0%

**Минимальный размер выборки:** 17 164 уникальных пользователя в каждой группе (всего 34 328 сессий).

### 2. Валидация и очистка данных (Data Integrity Check)

Исходный датасет содержал 294 480 строк. В процессе проверки качества работы сплит-системы выявлены и устранены следующие технические артефакты:

- **Несоответствия (mismatches):** удалено 3 893 строки, где пользователи из группы control видели new_page или из treatment видели old_page.
- **Повторные сессии:** обнаружены технические дубликаты записей. С помощью дедупликации по user_id сохранены только первые сессии пользователей.

Финальный объём чистой выборки после всех фильтров: **~290 585 уникальных пользователей**, что многократно превышает расчётный порог мощности тестов.

Распределение по группам:
- Группа Control (A): 145 274 пользователя
- Группа Treatment (B): 145 311 пользователей

### 3. Разведочный анализ и результаты статистического теста

- Конверсия Control (A): 12.039% (17 489 успехов)
- Конверсия Treatment (B): 11.892% (17 264 успеха)
- Фактическая разница (B - A): -0.147 п.п. (наблюдается незначительное падение)

Для проверки гипотезы использован **двухвыборочный Z-тест для пропорций (two-sided)**:

- Z-статистика: 1.3116
- p-value: 0.1897
- 95% доверительный интервал разности: [-0.394%, +0.078%]

График с доверительными интервалами подтверждает пересечение показателей групп.

### 4. Проверка стабильности во времени

Дополнительно проанализирована динамика конверсии по дням. Не выявлено значительных колебаний или эффекта новизны в первые дни теста, что подтверждает валидность полученных результатов.

---

## Итоговое аналитическое заключение

1. **Статистическая значимость:** отсутствует. p-value ≈ 0.19 значительно выше порогового α = 0.05. Наблюдаемые различия являются следствием случайного шума.

2. **Практическая значимость:** отсутствует. 95% доверительный интервал включает ноль. Фактический эффект далёк от целевого MDE = +1 п.п.

3. **Бизнес-рекомендация:**
   - **Не внедрять** новую версию страницы (new_page) для всех пользователей.
   - Оставить текущую версию лендинга (old_page), сэкономив ресурсы разработки.
   - Продуктовой команде: текущие изменения интерфейса не мотивируют пользователей к покупке. Необходимо сгенерировать новые гипотезы для тестирования.

---

## Ограничения анализа

- Данные не стратифицированы по типам пользователей (новые vs постоянные). Эффект может быть гетерогенным.
- Сезонные факторы не вычитались, однако период сбора данных (около месяца) позволяет нивелировать краткосрочные колебания.
- Технические артефакты (перекрёстные пользователи, дубликаты) обработаны, но полной гарантии чистоты данных нет, так как исходная система сплитования не контролировалась аналитиками.

---

## Следующие шаги

- Провести качественное исследование (юзабилити-тесты) для выявления причин низкой эффективности нового дизайна.
- Сформулировать альтернативные гипотезы с более крупным ожидаемым эффектом (например, изменение CTA или структуры страницы).
- При повторном тестировании увеличить MDE до 2 п.п. для более быстрого принятия решений.
