## Проекты в портфолио

### 1. End-to-End ML-сервис для прогнозирования оттока клиентов

*Стек: Python, LightGBM, Optuna, SHAP, FastAPI, Docker*

Разработал полноценный production-ready микросервис для прогнозирования оттока клиентов e-commerce платформы. Реализовал полный цикл DS-разработки: Feature Engineering с лаг-признаками и гео-данными, байесовскую оптимизацию гиперпараметров через Optuna (100 итераций), строгую Out-of-Time валидацию с TimeSeriesSplit. Провёл независимое сравнение CatBoost и LightGBM — победил LightGBM с ROC-AUC 0.7719 и PR-AUC 0.9981. Внедрил кастомную бизнес-метрику прибыли, оптимизировал порог принятия решений (0.01). Обеспечил интерпретируемость через SHAP-анализ и Error Analysis. Упаковал модель в Docker-контейнер с FastAPI-микросервисом.

🔗 **[Перейти к проекту](https://github.com/ValentinZavgorodnii/Zavgorodnii-Valentin/tree/main/end-to-end-churn-pipeline)**

### 2. Продвинутое A/B-тестирование: снижение дисперсии методом CUPED

*Стек: Python, NumPy, SciPy, Pandas, Matplotlib*

Спроектировал и реализовал с нуля математическую логику метода CUPED для повышения чувствительности A/B-тестов на зашумленных данных (логнормальное распределение с «китами»). Написал генератор синтетических панельных данных. Очистил целевую метрику от шума с помощью исторической ковариаты, добившись математически выверенного снижения дисперсии на 73.3%. Для строгого доказательства мощности алгоритма запрограммировал симуляцию Монте-Карло на 1000 итераций, которая подтвердила рост статистической мощности с 0% (у классического t-теста) до 100% (у CUPED-теста).

🔗 **[Перейти к проекту](https://github.com/ValentinZavgorodnii/Zavgorodnii-Valentin/tree/main/advanced-ab-testing-cuped)**

### 3. BI-дашборд для маркетинга (Apache Superset)

*Стек: Apache Superset, PostgreSQL, Docker, Redis*

Разработал интерактивную панель управления для отдела маркетинга на базе Apache Superset. Развернул инфраструктуру через docker-compose (Superset + Redis + PostgreSQL), настроил коннект к локальной витрине данных. Спроектировал семантический слой (Datasets) и строго сверял агрегации с прямыми SQL-запросами. Реализовал 5 ключевых визуализаций: RFM-сегментацию (Treemap), динамику выручки (Line Chart), когортную матрицу удержания (Heatmap) и KPIs. Настроил интерактивные кросс-фильтры (Cross-filtering) для исследования связей между сегментами и метриками.

### 4. Проектирование аналитического ELT-пайплайна и RFM-сегментация

*Стек: PostgreSQL (DDL/DML), Сложные CTE, Оконные функции, EXPLAIN ANALYZE, Индексы*

Разработал полноценный аналитический конвейер для обработки e-commerce данных (400k+ строк). Реализовал трёхслойную архитектуру DWH (Staging → Core → Marts). Написал модули для расчёта Month-over-Month (MoM) динамики выручки с помощью `LAG()` и автоматического квантильного RFM-скоринга через `NTILE()`. Провёл аудит производительности с помощью `EXPLAIN ANALYZE`, внедрив B-Tree индексацию, что ускорило точечные запросы поиска клиентов почти в 100 раз. Настроил автоматический экспорт готовой витрины в CSV для ML-моделей.
