## Проекты в портфолио

### 1. Проектирование аналитического ELT-пайплайна и RFM-сегментация
*Стек: PostgreSQL (DDL/DML), Сложные CTE, Оконные функции, EXPLAIN ANALYZE, Индексы*

Разработал полноценный аналитический конвейер для обработки e-commerce данных (400k+ строк). Реализовал трехслойную архитектуру DWH (Staging -> Core -> Marts). Написал модули для расчета Month-over-Month (MoM) динамики выручки с помощью `LAG()` и автоматического квантильного RFM-скоринга через `NTILE()`. Провел аудит производительности с помощью `EXPLAIN ANALYZE`, внедрив B-Tree индексацию, что ускорило точечные запросы поиска клиентов почти в 100 раз. Настроил автоматический экспорт готовой витрины в CSV для ML-моделей.

🔗 **[Перейти к проекту](https://github.com/ValentinZavgorodnii/Zavgorodnii-Valentin/tree/main/sql-retail-elt-pipeline)**

### 2. Динамический RFM-анализ с матрицей переходов (Python)
*Стек: pandas, numpy, matplotlib, seaborn*

Проведена глубокая сегментация клиентов по Recency, Frequency, Monetary. Построена матрица переходов между сегментами во времени (разделение данных по медианной дате). Выявлены критические точки оттока (50% новых клиентов уходят в Lost) и разработаны индивидуальные стратегии удержания для каждого кластера пользователей.

🔗 **[Перейти к проекту](https://github.com/ValentinZavgorodnii/Zavgorodnii-Valentin/tree/main/rfm_segmentation)**

### 3. A/B-тестирование: оптимизация конверсии лендинга
*Стек: pandas, numpy, matplotlib, seaborn, statsmodels*

Проведён полный цикл A/B-анализа: расчёт необходимого размера выборки и мощности (17 164 пользователя на группу), фильтрация пересекающихся пользователей и багов логирования. Выполнен двухвыборочный Z-тест для пропорций, построены доверительные интервалы. Принято взвешенное бизнес-решение на основе статистической и практической значимости.

🔗 **[Перейти к проекту](https://github.com/ValentinZavgorodnii/Zavgorodnii-Valentin/tree/main/ab-testing-ecommerce)**

---

### 4. Когортный анализ и LTV
*Стек: pandas, numpy, matplotlib, seaborn*

Построены когорты по месяцам первой покупки, рассчитаны Retention Rate и кумулятивный LTV на клиента. Выявлены сезонные аномалии (пик удержания 50% у когорты декабря 2010) и предложены маркетинговые рекомендации для улучшения удержания пользователей на критических стадиях жизненного цикла (2–3 месяцы).

🔗 **[Перейти к проекту](https://github.com/ValentinZavgorodnii/Zavgorodnii-Valentin/tree/main/cohort-retention-analysis)**

### 5. Разведочный анализ данных (EDA) и очистка
*Стек: pandas, numpy, matplotlib, seaborn, scipy.stats*

Реализован полный пайплайн предобработки: удаление аномалий по методу IQR, дедупликация, обработка пропусков, Feature Engineering (удельная стоимость, географические метрики). Сформулированы и проверены 4 бизнес-гипотезы с использованием непараметрических статистических тестов.

🔗 **[Перейти к проекту](https://github.com/ValentinZavgorodnii/Zavgorodnii-Valentin/tree/main/eda_online_retail)**
