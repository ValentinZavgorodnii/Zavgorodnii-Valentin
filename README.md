## Проекты в портфолио

### 1. End-to-End ML-сервис для прогнозирования оттока клиентов
*Стек: Python, LightGBM, Optuna, SHAP, FastAPI, Docker*

Разработал полноценный production-ready микросервис для прогнозирования оттока клиентов e-commerce платформы. Реализовал полный цикл DS-разработки: Feature Engineering с лаг-признаками и гео-данными, байесовскую оптимизацию гиперпараметров через Optuna (100 итераций), строгую Out-of-Time валидацию с TimeSeriesSplit. Провёл сравнение CatBoost и LightGBM — победил LightGBM с ROC-AUC 0.7719 и PR-AUC 0.9981. Внедрил кастомную бизнес-метрику прибыли, оптимизировал порог принятия решений (0.01). Обеспечил интерпретируемость через SHAP-анализ и Error Analysis. Упаковал модель в Docker-контейнер с FastAPI-микросервисом.

🔗 **[Перейти к проекту](https://github.com/ValentinZavgorodnii/Zavgorodnii-Valentin/tree/main/end-to-end-churn-pipeline)**

### 2. Проектирование аналитического ELT-пайплайна и RFM-сегментация
*Стек: PostgreSQL (DDL/DML), Сложные CTE, Оконные функции, EXPLAIN ANALYZE, Индексы*

Разработал полноценный аналитический конвейер для обработки e-commerce данных (400k+ строк). Реализовал трёхслойную архитектуру DWH (Staging → Core → Marts). Написал модули для расчёта Month-over-Month (MoM) динамики выручки с помощью `LAG()` и автоматического квантильного RFM-скоринга через `NTILE()`. Провёл аудит производительности с помощью `EXPLAIN ANALYZE`, внедрив B-Tree индексацию, что ускорило точечные запросы поиска клиентов почти в 100 раз. Настроил автоматический экспорт готовой витрины в CSV для ML-моделей.

🔗 **[Перейти к проекту](https://github.com/ValentinZavgorodnii/Zavgorodnii-Valentin/tree/main/sql-retail-elt-pipeline)**

### 3. Динамический RFM-анализ с матрицей переходов (Python)
*Стек: pandas, numpy, matplotlib, seaborn*

Провёл глубокуб сегментацию клиентов по Recency, Frequency, Monetary. Построил матрицу переходов между сегментами во времени (разделение данных по медианной дате). Выявил критические точки оттока (50% новых клиентов уходят в Lost) и разработал индивидуальные стратегии удержания для каждого кластера пользователей.

### 4. A/B-тестирование: оптимизация конверсии лендинга
*Стек: pandas, numpy, matplotlib, seaborn, statsmodels*

Провёл полный цикл A/B-анализа: расчёт необходимого размера выборки и мощности (17 164 пользователя на группу), фильтрация пересекающихся пользователей и багов логирования. Выполнил двухвыборочный Z-тест для пропорций, построил доверительные интервалы. Принял взвешенное бизнес-решение на основе статистической и практической значимости.

*Стек: pandas, numpy, matplotlib, seaborn*
