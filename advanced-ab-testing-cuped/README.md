# Сравнение мощности A/B-тестов: снижение дисперсии с помощью CUPED

**Автор:** Валентин Завгородний  
**Стек:** Python, NumPy, pandas, SciPy, Matplotlib

Исследование влияния CUPED на чувствительность A/B-тестов метрики выручки. В проекте реализованы генератор синтетических данных, корректировка метрики с помощью предэкспериментальной ковариаты и сравнение тестов в независимых симуляциях Монте-Карло.

**Основной результат:** при заданном эффекте +15 денежных единиц на пользователя оценка мощности выросла с **43,2% до 92,6%**. Среднее снижение дисперсии составило **73,34%**. Дополнительно проведены **5000 A/A-экспериментов** для оценки частоты ложных срабатываний.

Результаты относятся к описанному ниже синтетическому сценарию.

## Задача

Выручка на пользователя может сильно различаться: небольшое число крупных покупателей увеличивает разброс метрики. При фиксированных размере выборки и эффекте высокая дисперсия затрудняет обнаружение изменений.

Цель проекта — проверить, помогает ли историческая выручка снизить дисперсию текущей метрики и увеличить мощность теста, сохраняя частоту ложных срабатываний вблизи заданного уровня значимости.

## Данные и дизайн эксперимента

| Параметр | Значение |
|---|---|
| Пользователи | 100 000 в каждом эксперименте суммарно |
| Разделение на группы | Случайное, вероятность попадания в каждую группу — 50% |
| Историческая метрика | Логнормальное распределение: mu = 6, sigma = 1,2 |
| Текущая метрика до воздействия | Линейная связь с исторической метрикой + нормальный шум; отрицательные значения заменяются нулём |
| Эффект в A/B | +15 денежных единиц каждому пользователю тестовой группы |
| Эффект в A/A | 0 |
| Уровень значимости | 0,05 |
| Статистический тест | Двусторонний t-тест Уэлча, equal_var=False |
| A/B-симуляции | 1000 независимых повторений |
| A/A-симуляции | 5000 независимых повторений |

Параметр генератора `correlation=0.8` задаёт связь метрик **до обрезания отрицательных значений**. Он не равен фактической корреляции после преобразования: в демонстрационной выборке она составляет примерно 0,856.

Историческая метрика логнормальна; итоговая текущая метрика после добавления шума и обрезания не имеет чисто логнормального распределения.

## Метод CUPED

Историческая выручка используется как ковариата для корректировки текущей метрики:

$$
Y_{\mathrm{CUPED}} = Y - \hat{\theta}(X - \bar{X}),
\qquad
\hat{\theta} = \frac{\widehat{\operatorname{Cov}}(Y,X)}
{\widehat{\operatorname{Var}}(X)}.
$$

Здесь:

- $Y$ — выручка пользователя в эксперименте;
- $X$ — его выручка в предэкспериментальном периоде;
- $\bar{X}$ — среднее значение ковариаты по объединённой выборке;
- $\hat{\theta}$ — коэффициент линейной корректировки, оценённый по объединённой выборке.

Затем сравниваются средние скорректированной метрики в контрольной и тестовой группах с помощью t-теста Уэлча.

Для оптимального коэффициента линейной корректировки выполняется:

$$
\operatorname{Var}(Y_{\mathrm{CUPED}})
=
\operatorname{Var}(Y)(1-\rho^2),
$$

где $\rho$ — фактическая корреляция между метрикой и ковариатой. Чем сильнее связь, тем больше потенциальное снижение дисперсии. Для применения в эксперименте ковариата должна быть измерена до воздействия и не зависеть от него.

## Результаты

### Один демонстрационный эксперимент

Для выборки с `random_state=42` и эффектом +15:

| Показатель | Исходная метрика | После CUPED |
|---|---:|---:|
| t-статистика | 0,89 | 4,39 |
| p-value | 0,3735 | 0,000012 |
| Решение при α = 0,05 | Не отвергаем H₀ | Отвергаем H₀ |

Снижение дисперсии в этой выборке — **73,318%**.

В одном эксперименте CUPED позволил обнаружить заложенный эффект, который не был обнаружен тестом по исходной метрике. Для оценки мощности нужны многократные независимые повторения.

### Мощность: 1000 A/B-экспериментов

Мощность оценивается как доля экспериментов, в которых тест отклонил H₀ при наличии заложенного эффекта +15.

| Метод | Отклонений H₀ | Оценка мощности | 95% доверительный интервал |
|---|---:|---:|---:|
| t-тест Уэлча по исходной метрике | 432 / 1000 | **43,2%** | [40,2%; 46,3%] |
| t-тест Уэлча после CUPED | 926 / 1000 | **92,6%** | [90,8%; 94,1%] |

Рост оценённой мощности — **49,4 процентного пункта**. Среднее снижение дисперсии по повторениям — **73,34%**.

Средняя оценка эффекта составила 14,794 по исходной метрике и 14,967 после CUPED при заложенном значении 15.

### Ложные срабатывания: 5000 A/A-экспериментов

В A/A-сценарии воздействие отсутствует. Отклонение H₀ является ложным срабатыванием.

| Метод | Ложных срабатываний | Частота | 95% доверительный интервал |
|---|---:|---:|---:|
| t-тест Уэлча по исходной метрике | 259 / 5000 | **5,18%** | [4,6%; 5,8%] |
| t-тест Уэлча после CUPED | 275 / 5000 | **5,50%** | [4,9%; 6,2%] |

Оба интервала включают заданный уровень 5%. Результаты согласуются с этим уровнем в исследованном сценарии; они не доказывают корректность тестов при любых распределениях и условиях.

Все интервалы в таблицах симуляций рассчитаны **методом Уилсона для доли**. Они характеризуют неопределённость оценки мощности или частоты ложных срабатываний, а не величины эффекта на выручку.

## Воспроизводимость

В каждом повторении генерируется новая выборка. Дочерние seed создаются через `np.random.SeedSequence(...).spawn(n_trials)`, затем передаются генератору с локальным `RandomState`.

- Seed демонстрационного эксперимента: 42.
- Seed A/A-прогона: 2026.
- Seed A/B-прогона: 2027.

Такой подход позволяет воспроизвести весь прогон и избежать повторения одной выборки внутри симуляции.

## Практический вывод и ограничения

В этом сценарии CUPED повысил вероятность обнаружить небольшое изменение средней выручки при том же числе пользователей. На практике это делает метод полезным кандидатом для экспериментов с информативными историческими метриками.

При интерпретации результатов необходимо учитывать:

- Сильная связь исторической и текущей метрик специально заложена в генератор.
- Эффект одинаков для всех пользователей тестовой группы. Не исследованы неоднородность эффекта, сезонность, пропуски исторических данных и пользователи без истории.
- Показатель снижения дисперсии рассчитан по объединённой пользовательской метрике; он не заменяет проверку дисперсии оценки разницы между группами.
- Исследована одна конфигурация размера выборки, распределений и эффекта.
- Экономия денег и сокращение длительности реальных экспериментов не измерялись. Для таких выводов нужны данные о трафике, бизнес-метриках и условиях эксперимента.
