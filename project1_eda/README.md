# Исследовательский анализ данных продаж (Online Retail EDA)

Этот проект представляет собой комплексный аналитический кейс по обработке и исследованию исторических данных о транзакциях интернет-магазина. Основная цель работы — предобработка «сырых» данных, устранение технических аномалий и извлечение ключевых бизнес-метрик для оптимизации маркетинга и ассортимента.

## Основные задачи и этапы проекта

### 1. Контроль качества и предобработка данных
- Удаление записей без идентификатора клиента (`CustomerID`).
- Обнаружение и удаление **5 225 полных дубликатов строк** (результат технических сбоев логирования).
- Приведение типов данных: `CustomerID` → `int`, `InvoiceDate` → `datetime`.
- Расчёт выручки по каждой транзакции: `Revenue = Quantity * UnitPrice`.

### 2. Исследование выбросов и фильтрация мусора
- Анализ распределения `Quantity` и `UnitPrice` через `.describe()` для выявления аномалий.
- **Обоснованная фильтрация системного мусора**:
  - В датасете все корректные названия товаров записаны ЗАГЛАВНЫМИ буквами.
  - Строки, содержащие строчные буквы, являются техническим браком (примеры выведены в коде: `'?'`, `'manual'`, `'postage'` и т.д.).
  - Применён фильтр `.str.isupper() == True`, удаляющий только невалидные записи.
- Разделение данных на **чистые продажи** (`Quantity > 0`) и **возвраты** (`Quantity < 0`) для корректного финансового анализа.

### 3. Анализ возвратов
- Подсчёт общего количества возвращённых товаров (в штуках).
- Выявление топ-5 товаров, наиболее часто возвращаемых.
- Расчёт **процента возвратов от общей выручки**:  
  `(сумма выручки по возвратам / сумма выручки по продажам) * 100%`.

### 4. Товарный анализ (ассортиментная матрица)
- Визуализация топ-10 товаров, приносящих максимальную выручку.
- Определение товаров-аутсайдеров (с наименьшей суммарной выручкой) для оптимизации складских запасов.

### 5. Географический анализ
- Распределение количества транзакций по странам.
- Расчёт **средней и медианной выручки** по странам:
  - Среднее значение чувствительно к выбросам (например, единичные крупные оптовые заказы).
  - Медиана показывает типичный чек для большинства покупателей.
- Сравнение метрик позволяет избежать ложных выводов о «ёмкости рынка».

### 6. Временной анализ
- Агрегация выручки по месяцам (поле `InvoiceMonth`).
- Построение линейного графика с **динамической аннотацией** пикового месяца
- Выявление сезонности: значительный рост продаж в ноябре.

### 7. Анализ концентрации клиентской базы
- Группировка выручки по клиентам (`CustomerID`).
- Расчёт доли топ-10 клиентов в общей выручке (правило Парето).
- Вывод о необходимости CRM-стратегий для удержания VIP-сегмента.

## Технологический стек
- **Python** — язык анализа.
- **Pandas** — дедупликация, фильтрация, агрегации (`groupby`, `merge`), описательная статистика.
- **Matplotlib** — визуализация (`barh`, `line`), динамические аннотации.
- **Jupyter Notebook** — интерактивная среда с документированием кода.

## Ключевые бизнес-инсайты

1. **Качество данных восстановлено**  
   Удаление 5 225 дубликатов и фильтрация системного мусора повысили достоверность всех последующих расчётов.

2. **Возвраты не критичны, но есть лидеры**  
   - Процент возвратов от общей выручки составил **-5.47** .  
   - Топ-5 возвращаемых товаров указывает на возможные проблемы с качеством или описанием (например, `"POPPY'S PLAYHOUSE"`, `"JUMBO BAG WOODEN ANIMALS"`). Рекомендуется проверить эти позиции.

3. **Средняя выручка по странам обманчива**  
   - В Нидерландах и Австралии **средний чек** высок за счёт редких оптовых заказов, но **медианный чек** низкий — значит, массовый покупатель там тратит немного.  
   - Великобритания лидирует по количеству транзакций и показывает стабильную медиану, что подтверждает розничную модель.

4. **Ярко выраженная сезонность**  
   Пик продаж приходится на ноябрь (предпраздничный период). Рекомендуется наращивать запасы популярных товаров с октября.

5. **Высокая концентрация выручки на топ-10 клиентах**  
   Доля составляет около **17.4%**. Риск потери крупных покупателей требует внедрения программ лояльности и персональных коммуникаций.

3. Все ключевые метрики (процент возвратов, медианная выручка по странам, топ возвратов) вычисляются автоматически.
