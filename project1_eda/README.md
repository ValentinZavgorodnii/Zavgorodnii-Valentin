# Исследовательский анализ данных продаж (Online Retail EDA)

Этот проект представляет собой комплексный аналитический кейс по обработке и исследованию исторических данных о транзакциях интернет-магазина. Основная цель работы — предобработка «сырых» данных, устранение технических аномалий и извлечение ключевых бизнес-метрик для оптимизации маркетинга и ассортимента.

## Основные задачи и этапы проекта

1. **Контроль качества и предобработка данных:**
   - Очистка от пропущенных значений (удаление записей без `CustomerID`).
   - Идентификация и удаление **5 225 полных дубликатов строк**, возникших вследствие технических сбоев системы логирования.
   - Приведение форматов данных к корректным типам (`int` для ID клиентов, `datetime` для дат транзакций).

2. **Осознанная фильтрация и валидация бизнес-логики:**
   - Очистка от системного мусора (брак, складские списания, административные корректировки) с помощью валидации регистра описания товаров (`.str.isupper()`).
   - Разделение единого потока данных на **чистые продажи** (`Quantity > 0`) и **возвраты** (`Quantity < 0`) для предотвращения искажения финансовой отчетности.

3. **Товарный анализ (Ассортиментная матрица):**
   - Расчет и визуализация топ-10 товаров, генерирующих максимальный объем выручки.
   - Определение критических аутсайдеров — топ-10 товаров с минимальной совокупной выручкой за весь период для оптимизации складских запасов.

4. **Географический и временной анализ:**
   - Сравнение транзакционной активности по странам и расчет средней выручки.
   - Анализ временных рядов (помесячно) с автоматическим динамическим расчетом пиковых периодов. Выявлен выраженный сезонный всплеск продаж в ноябре.

5. **Анализ концентрации клиентской базы:**
   - Группировка выручки по клиентам и расчет доли топ-10 покупателей в общем финансовом результате компании (Анализ по принципу Парето).

## Технологический стек
* **Python**
* **Pandas** — дедупликация, фильтрация, динамическая агрегация (`groupby`) и трансформация данных.
* **Matplotlib** — построение графиков (barh, line) и создание динамических аннотаций без использования хардкода.
* **Jupyter Notebook** — среда для интерактивной разработки.

## Ключевые бизнес-инсайты
- **Стабильность архитектуры кода:** Использование динамических обращений (`.loc` и `.max()`) в визуализации гарантирует корректность отображения графиков при обновлении и дозагрузке данных.
- **Сезонность:** Бизнес имеет ярко выраженный пик продаж в конце года (ноябрь), что требует заблаговременного планирования логистики и складских остатков.
- **Концентрация рисков:** Анализ показал высокую долю выручки, приходящуюся на топ-10 клиентов, что подчеркивает необходимость внедрения CRM-стратегий и программ лояльности для удержания VIP-сегмента.
