# Исследовательский анализ данных продаж (Online Retail EDA)

Этот проект представляет собой комплексный анализ данных о продажах интернет-магазина. Основная цель работы — применить инструменты Python (Pandas, Matplotlib) для извлечения бизнес-инсайтов из «сырых» данных.

## Основные задачи и этапы проекта
1. **Предобработка данных:**
   - Очистка от пропущенных значений в `CustomerID`.
   - Приведение форматов дат и типов данных к корректному виду.
   - Фильтрация аномалий (устранение некорректных описаний товаров).
2. **Анализ популярных товаров:**
   - Определение топ-10 товаров, приносящих наибольшую выручку.
3. **Географический анализ:**
   - Сравнение объемов транзакций по странам.
   - Выявление различий в поведении покупателей (розничная модель в Великобритании vs оптовая модель в Нидерландах и Австралии).
4. **Анализ временных рядов:**
   - Исследование сезонности продаж.
   - Визуализация пиков выручки, связанных с праздничным сезоном.
5. **Анализ клиентской базы:**
   - Расчет концентрации выручки (Анализ по принципу Парето).
   - Выявление ключевых клиентов, формирующих ядро продаж.

## Технологический стек
* **Python**
* **Pandas** — манипуляция и агрегация данных.
* **Matplotlib** — визуализация данных и построение трендов.
* **Jupyter Notebook** — среда разработки и документирования.

## Ключевые выводы
- Бизнес-модель компании существенно различается в зависимости от региона: в то время как Великобритания является основным рынком розничных продаж, европейские и азиатские рынки характеризуются крупными оптовыми чеками.
- Обнаружена ярко выраженная сезонность с пиком выручки в ноябре.
- Существует высокая концентрация выручки: 16.5% общего дохода приносят всего 10 крупнейших клиентов, что указывает на необходимость стратегии по удержанию VIP-сегмента.
