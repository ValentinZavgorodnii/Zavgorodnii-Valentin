## 📊 Структура анализа
В процессе работы были выполнены следующие этапы:
1. **Загрузка и предобработка:** Заполнение пропусков, проверка типов данных, удаление дубликатов.
2. **Анализ распределений:** Изучение распределения числовых признаков (гистограммы, Boxplots).
3. **Корреляционный анализ:** Поиск зависимостей между переменными (Heatmap).
4. **Ответы на бизнес-вопросы:**
